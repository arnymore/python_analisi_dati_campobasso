# 💡 Soluzioni Ufficiali del Docente

Questa cartella contiene il codice di riferimento per tutti i laboratori pratici del corso.

---

## 📋 Indice delle Soluzioni

| File Soluzione | Laboratorio Corrispondente | Descrizione Tecnica |
| :--- | :--- | :--- |
| `sol01_python_operativo.py` | Modulo 1 (2h) | Funzioni di calcolo totale riga, normalizzazione anagrafiche e aggregazioni native con dizionari. |
| `sol02_pandas_fondamenti.py` | Modulo 2 (4h) | Caricamento Excel, metadati DataFrame, filtri booleani `.loc`/`.iloc`, colonne calcolate e ordinamento Top Deals. |
| `sol03_data_wrangling.py` | Modulo 3 (3h) | Deduplicazione, normalizzazione testi/categorie, parsing date miste/seriali, merge anagrafica clienti e report `.agg()`. |
| `sol04_visualizzazione.py` | Modulo 4 (3h) | Matplotlib & Seaborn: barplot Top Clienti, trend mensile, heatmap vendite ed Executive Dashboard 2x2. |
| `sol05_automazione_pipeline.py` | Modulo 5 (2h) | Pipeline ETL batch end-to-end con supporto CLI argparse, logging, Parquet ed Excel multi-scheda. |
| `sol06_dashboard_streamlit.py` | Modulo 6 (4h) | Script per l'avvio della dashboard Streamlit con layout avanzato e simulatore What-If. |
| `sol07_deploy_linux.sh` | Modulo 7 (1h) | Script Bash di provisioning del servizio Systemd su server Linux. |

---

## 🚀 Istruzioni di Esecuzione per il Docente

Per eseguire una soluzione direttamente dal terminale:

```bash
# Esempio: test soluzione Modulo 3
python soluzioni/sol03_data_wrangling.py

# Esempio: esecuzione pipeline ETL consolidata
python soluzioni/sol05_automazione_pipeline.py

# Esempio: avvio dashboard interattiva
streamlit run soluzioni/sol06_dashboard_streamlit.py
```
