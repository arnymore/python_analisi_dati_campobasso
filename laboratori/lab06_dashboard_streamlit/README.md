# Laboratorio 6: Dashboard Interattive con Streamlit (4 Ore)

## 🎯 Obiettivi
* Comprendere l'architettura reattiva e il paradigma low-code di Streamlit.
* Ottimizzare le performance di caricamento con il caching `@st.cache_data`.
* Costruire una sidebar interattiva con filtri dinamici (multiselect, date input).
* Creare schede riepilogative con indicatori KPI (`st.metric`) in colonne.
* Realizzare un simulatore di scenari ("What-If Analysis") e pulsanti di download dati in formato CSV.

## 📄 File di Lavoro
* `app_starter.py`: File di partenza con la struttura base e sezioni `# TODO:` da arricchire.
* Dataset di riferimento: `dataset/generated/vendite_consolidate_italia.parquet`.

## 🚀 Esecuzione
```bash
streamlit run laboratori/lab06_dashboard_streamlit/app_starter.py
```
Soluzione completa ed evoluta: `dashboard/app.py` (o `soluzioni/sol06_dashboard_streamlit.py`).
