# Laboratorio 3: Data Wrangling, Pulizia e Integrazione (3 Ore)

## 🎯 Obiettivi
* Identificare e rimuovere record duplicati con `.drop_duplicates()`.
* Diagnosticare e trattare valori mancanti (strategie di imputazione condizionale per gruppo).
* Risolvere il problema delle date disomogenee (formati IT, US, seriali Excel, mesi testuali).
* Normalizzare testi e categorie merceologiche con funzioni di mappatura.
* Eseguire la JOIN relazionale (`pd.merge`) tra dati di vendita e anagrafica clienti.
* Calcolare metriche aggregate per settore e filiale con `groupby().agg()`.
